## English

- **AI provider switch fix**: choosing a cloud provider (or saving an API key) clears a stuck `local_only` / demo-polluted config so the picker and saved keys work again. Demo mode no longer writes into the real Application Support config.

## Česky

- **Oprava přepínače AI poskytovatele**: výběr cloudového poskytovatele (nebo uložení API klíče) zruší zaseknuté `local_only` / konfiguraci z demo režimu, aby přepínač a uložené klíče znovu fungovaly. Demo režim už nepíše do skutečné Application Support konfigurace.
