## English

- **No more doubled messages in Gmail conversations:** Gmail keeps every message also in All Mail, so an opened conversation showed each message twice. Each message is now shown once (the same for mail to yourself, which sits in Inbox and Sent).

## Česky

- **Zprávy v konverzacích Gmailu už nejsou dvakrát:** Gmail má každou zprávu i ve „Všech zprávách“, takže otevřená konverzace ukazovala každou zprávu dvakrát pod sebou. Teď je každá zpráva jen jednou (totéž u pošty sobě, která je v Doručené i Odeslané).
