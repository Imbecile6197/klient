## English

- **Klient uses only the AI models you set.** The Test button next to an API key used the provider's most expensive default model (for Gemini, 3.1 Pro) when no role used that provider; it now uses the configured model or the provider's cheap one. When you switch a role to another provider and back, the model you chose before is restored instead of the expensive default.
- **Every AI request is recorded in the system log** – provider, model, size, duration and result, never the content. Check it with `journalctl --user -g "AI request"`.

## Česky

- **Klient používá jen modely AI, které nastavíte.** Tlačítko Test u API klíče používalo nejdražší výchozí model poskytovatele (u Gemini 3.1 Pro), když ho žádná role nepoužívala; teď použije nastavený model nebo levný model poskytovatele. Když roli přepnete na jiného poskytovatele a zpět, vrátí se dřív zvolený model místo drahého výchozího.
- **Každý požadavek na AI se zapisuje do systémového logu** – poskytovatel, model, velikost, doba a výsledek, nikdy obsah. Ověříte ho příkazem `journalctl --user -g "AI request"`.
