## English

- **Faster open / navigate**: opening a message no longer forces a full list reload; spam badges patch the row locally; archive/star/read run off the main thread with optimistic UI.
- **Faster select→render**: header shows from the list immediately; `MarkRead` no longer blocks `getFull`; next/prev messages are prefetched (without clearing unread); WKWebView keeps CSP in `<head>` and skips a second HTML pass.
- **Quieter Proton storms**: `mailChanged` events coalesce (~400ms) on top of the existing 2s UI debounce; bridge events parse off-main.
- **Cheaper reader**: HTMLView skips rebuilds when content is unchanged; `getFull` no longer ships duplicate HTML / inline image maps across the bridge.
- **Snappier start**: config/labels apply before `resumeAll` finishes.

## Česky

- **Rychlejší otevírání**: otevření zprávy už nespouští plný reload seznamu; spam odznaky se doplní lokálně; archiv/hvězda/přečteno běží mimo hlavní vlákno s optimistic UI.
- **Rychlejší select→render**: hlavička ze seznamu hned; `MarkRead` neblokuje `getFull`; next/prev se přednačítá (bez mazání nepřečtených); WKWebView drží CSP v `<head>` a vynechá druhý HTML průchod.
- **Klidnější Proton eventy**: `mailChanged` se slučuje (~400 ms) navíc k 2s debounce v UI; parsování eventů mimo main.
- **Levnější čtečka**: HTMLView se nepřekreslí bez změny obsahu; `getFull` neposílá duplicitní HTML / mapu inline obrázků přes bridge.
- **Rychlejší start**: config/štítky se aplikují ještě před dokončením `resumeAll`.
