## English

- **Automatic updates from GitHub releases**: a new version is downloaded in the background, verified by SHA-256 (against both `SHA256SUMS` and GitHub's own digest) and installed after one click and the administrator password (Preferences → Messages → Updates).

**Install:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm`

## Česky

- **Automatické aktualizace z vydání na GitHubu**: nová verze se stáhne na pozadí, ověří se kontrolním součtem SHA-256 (proti souboru `SHA256SUMS` i otisku, který uvádí GitHub) a nainstaluje se jedním kliknutím a heslem správce (Předvolby → Zprávy → Aktualizace).

**Instalace:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm`
