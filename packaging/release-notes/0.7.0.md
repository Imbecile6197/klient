## English

Klient now speaks **English and Czech**.

- The interface follows the system language; it can be changed in Preferences → Messages → Interface language.
- The AI answers in the interface language too – summaries, reply suggestions, “Ask Your Mail” and the spam filter's reasons.
- Complete documentation in both languages (Help, F1), README in English and Czech.
- Dates, times and plurals are formatted properly for each language.
- The error hints for AI providers and the About dialog were brushed up; bug reports now go to GitHub Issues.

**Install:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm` – an installed Klient then updates itself (Preferences → Messages → Updates).

## Česky

Klient teď mluví **anglicky a česky**.

- Rozhraní se řídí jazykem systému; změnit ho jde v Předvolbách → Zprávy → Jazyk rozhraní.
- Stejným jazykem odpovídá i AI – shrnutí, návrhy odpovědí, „Zeptat se pošty“ a zdůvodnění spamfiltru.
- Kompletní dokumentace v obou jazycích (Nápověda, F1), README anglicky i česky.
- Data, časy a tvary slov podle počtu se v každém jazyce píšou správně.
- Doladěné nápovědy k chybám poskytovatelů AI a okno O aplikaci; chyby se nově hlásí přes GitHub Issues.

**Instalace:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm` – nainstalovaný Klient se pak aktualizuje sám (Předvolby → Zprávy → Aktualizace).
