## English

- **Klient as a Flatpak.** Klient now also comes as a Flatpak for any distribution, including those whose system libraries are too old for the RPM or deb. Install it with `flatpak install --user https://imbecile6197.github.io/klient/eu.libormacak.Klient.flatpakref`, or download `klient.flatpak` from this release and open it in GNOME Software. It comes from Klient's own signed repository, and updates arrive through GNOME Software or `flatpak update`.
- In the Flatpak, starting after login goes through the system (Settings → Apps), and the default mail app is chosen in GNOME Settings → Apps → Default Apps.

## Česky

- **Klient jako Flatpak.** Klient je teď i jako Flatpak pro jakoukoli distribuci, včetně těch, jejichž systémové knihovny jsou na RPM nebo deb příliš staré. Nainstalujete ho příkazem `flatpak install --user https://imbecile6197.github.io/klient/eu.libormacak.Klient.flatpakref`, nebo si z tohoto vydání stáhněte `klient.flatpak` a otevřete ho v GNOME Software. Pochází z vlastního podepsaného repozitáře Klienta a aktualizace přicházejí přes GNOME Software nebo `flatpak update`.
- Ve Flatpaku jde spouštění po přihlášení přes systém (Nastavení → Aplikace) a výchozí poštovní aplikace se vybírá v Nastavení GNOME → Aplikace → Výchozí aplikace.

## Deutsch

- **Klient als Flatpak.** Klient gibt es jetzt auch als Flatpak für jede Distribution, auch für solche, deren Systembibliotheken für RPM oder deb zu alt sind. Installieren Sie es mit `flatpak install --user https://imbecile6197.github.io/klient/eu.libormacak.Klient.flatpakref`, oder laden Sie `klient.flatpak` aus dieser Version herunter und öffnen Sie es in GNOME Software. Es kommt aus Klients eigenem signiertem Repository, und Aktualisierungen kommen über GNOME Software oder `flatpak update`.
- Im Flatpak läuft der Start nach der Anmeldung über das System (Einstellungen → Apps), und die Standard-Mail-App wählen Sie in den GNOME-Einstellungen → Apps → Standard-Apps.
