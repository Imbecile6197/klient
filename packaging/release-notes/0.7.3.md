## English

- **Ubuntu package:** Klient is now also released as a `.deb` package for Ubuntu 26.04 LTS and newer.
- **Automatic updates on Ubuntu:** a Klient installed from the `.deb` package downloads the new `.deb` and installs it with apt, like the Fedora version does with dnf.

**Install on Fedora:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm`

**Install on Ubuntu:** `wget https://github.com/Imbecile6197/klient/releases/latest/download/klient_amd64.deb && sudo apt install ./klient_amd64.deb`

## Česky

- **Balíček pro Ubuntu:** Klient teď vychází i jako balíček `.deb` pro Ubuntu 26.04 LTS a novější.
- **Automatické aktualizace na Ubuntu:** Klient nainstalovaný z balíčku `.deb` si stáhne nový `.deb` a nainstaluje ho přes apt, stejně jako verze pro Fedoru přes dnf.

**Instalace na Fedoře:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm`

**Instalace na Ubuntu:** `wget https://github.com/Imbecile6197/klient/releases/latest/download/klient_amd64.deb && sudo apt install ./klient_amd64.deb`
