## English

- **New Preferences page, General:** the interface language, the default email application, running in the background, starting after login and updates have moved here from Messages. The Messages page now holds only settings for mail itself: threads, sending, the offline cache and the signature.

## Česky

- **Nová stránka Předvoleb Obecné:** jazyk rozhraní, výchozí e-mailová aplikace, běh na pozadí, spouštění po přihlášení a aktualizace se sem přesunuly ze Zpráv. Stránka Zprávy teď obsahuje jen nastavení samotné pošty: vlákna, odesílání, offline cache a podpis.
