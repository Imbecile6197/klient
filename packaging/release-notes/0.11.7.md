## English

- **Open at Login** in Settings → General: Klient can register as a macOS Login Item (`SMAppService`) and start when you sign in to the Mac.
- **macOS AI search and summarize** work more reliably: summarize uses the full message (including HTML), and related bridge paths handle failures without empty results.
- **Proton login sheet no longer flashes** when the account is still signed in. Transient network or keyring blips no longer open the sign-in dialog; only a real auth loss does.
- **Czech spam-scan status** after “Scan Inbox for Spam” matches the UI language (progress and completion). Unified inbox scan unwraps message IDs correctly.

## Česky

- **Spouštět při přihlášení** v Nastavení → Obecné: Klient se zaregistruje jako Login Item (`SMAppService`) a spustí se při přihlášení k Macu.
- **macOS AI hledání a shrnutí** spolehlivěji: shrnutí bere celou zprávu (včetně HTML) a související cesty v bridge lépe zvládají chyby.
- **Přihlašovací okno Protonu už nevyskakuje** náhodně, když je účet stále přihlášený. Krátké výpadky sítě nebo klíčovky neotevírají dialog; jen skutečná ztráta session.
- **České hlášky po kontrole spamu** („Prohledat doručenou poštu na spam“) odpovídají jazyku rozhraní. Ve sjednocené schránce se správně rozbalují ID zpráv.
