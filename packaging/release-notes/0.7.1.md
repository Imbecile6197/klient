## English

- **What's New after an update**: after Klient updates, it shows what has changed since the version you used last – in the window, or as a notification when it starts in the background. You can open it any time from the main menu → What's New.
- **See the changes before installing**: the “A new version is ready” notification and Preferences → Messages → Updates have a What's New button with the notes of the downloaded version.
- The About dialog shows the notes of the current version in the interface language.

**Install:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm`

## Česky

- **Co je nového po aktualizaci**: po aktualizaci Klient ukáže, co se změnilo od verze, kterou jste používali naposledy – v okně, nebo oznámením, když se spouští na pozadí. Kdykoli ho otevřete z hlavní nabídky → Co je nového.
- **Změny ještě před instalací**: oznámení „Je připravená nová verze“ a Předvolby → Zprávy → Aktualizace mají tlačítko Co je nového s poznámkami stažené verze.
- Okno O aplikaci ukazuje poznámky k aktuální verzi v jazyce aplikace.

**Instalace:** `sudo dnf install https://github.com/Imbecile6197/klient/releases/latest/download/klient.x86_64.rpm`
