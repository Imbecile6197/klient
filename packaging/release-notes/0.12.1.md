## English

- **No more pop-ups from the sync.** The messages in which Klient keeps the data shared between your computers showed up as new mail with a notification. Klient now recognises them (also those stored by 0.12.0) and never notifies about them or lists them – on every computer, with sync on or off.
- **Updates with macOS releases in the same repository.** Klient now takes the newest release that has a package for Linux and skips releases that are only for macOS.
- **Spam check retried.** When the AI could not be asked (no connection, the service down), the message got a fallback verdict and was never checked again. Now it is checked again after 30 minutes.
- **Faster opening of messages.** The message you click is fetched right away, at the same time as the rest of the conversation, and marking it as read no longer holds up showing it.
- **Snoozed and scheduled mail of IMAP accounts is shared between computers.** Only one computer returns snoozed mail and sends scheduled mail (the main one when it runs and has the account), and before sending it checks the server: a message another computer already sent is never sent twice.

## Česky

- **Synchronizace už nevyskakuje.** Zprávy, ve kterých Klient uchovává data sdílená mezi vašimi počítači, se ukazovaly jako nová pošta s upozorněním. Klient je teď pozná (i ty uložené verzí 0.12.0) a nikdy na ně neupozorní ani je nezobrazí v seznamu – na žádném počítači, se synchronizací zapnutou i vypnutou.
- **Aktualizace s vydáními pro macOS ve stejném repozitáři.** Klient teď vezme nejnovější vydání, které obsahuje balíček pro Linux, a vydání jen pro macOS přeskočí.
- **Kontrola spamu se zopakuje.** Když AI nešla zavolat (bez připojení, výpadek služby), zpráva dostala náhradní verdikt a už se nikdy znovu nezkontrolovala. Teď se zkontroluje znovu po 30 minutách.
- **Rychlejší otevírání zpráv.** Zpráva, na kterou kliknete, se stahuje hned, souběžně se zbytkem konverzace, a označení jako přečtené už její zobrazení nezdržuje.
- **Odložená a naplánovaná pošta u IMAP účtů se sdílí mezi počítači.** Odloženou poštu vrací a naplánovanou odesílá jen jeden počítač (hlavní, když běží a má daný účet) a před odesláním se zeptá serveru: zprávu, kterou už odeslal jiný počítač, nikdy neodešle podruhé.
