## English

- **HTML signature:** in Preferences → Messages → Signature, choose the *HTML* format. Paste your own HTML, open an .html file or start from a template, and see a live preview as recipients will see it. In a new message the signature is shown as a preview (remove it with ×) and is sent as HTML; recipients without HTML get a plain-text version. Scripts and similar content are removed from the signature.

## Česky

- **HTML podpis:** v Předvolbách → Zprávy → Podpis zvolte formát *HTML*. Vložte vlastní HTML, otevřete soubor .html, nebo začněte od šablony a hned vidíte náhled tak, jak ho uvidí příjemci. V nové zprávě je podpis vložený jako náhled (odeberete ho křížkem) a odešle se jako HTML; příjemci bez HTML dostanou textovou verzi. Skripty a podobný obsah se z podpisu odstraní.
